# Code of Conduct

skuzic follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Short version: be kind, assume good faith, critique ideas rather than people.
Harassment of any kind isn't tolerated.

To report a problem, contact the maintainer, [@thisisvaze](https://github.com/thisisvaze),
through the contact details on their GitHub profile.
